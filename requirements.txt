# Version policy (Auxi_Connector's): every dependency is version-bounded, with an
# upper bound at the next major, or tighter where a minor release has broken us or
# where we rely on internals. Minor/patch drift inside a bound is allowed so security
# fixes still flow; CI's pip-audit and the gate's pin check catch the rest. The
# floors are the versions the tests last ran against.
